#  BabyMeal

## Description

BabyMeal est une application web destinée aux jeunes parents.
Elle permet de consulter des recettes simples et adaptées à l’âge du bébé.

## Objectifs du projet

- Créer une interface moderne et accessible
- Proposer des recettes gratuites
- Aider les jeunes parents

## Technologies utilisées

- HTML5
- CSS3
- JavaScript

## Fonctionnalités

- Affichage de recettes
- Filtre par âge
- Page conseils
- Section encouragements

## Maquettage

Une maquette interactive a été réalisée avec Figma afin de concevoir
l’interface utilisateur du projet avant le développement front-end.

## Prototype Figma

Le prototype présente :
- la page d’accueil
- la navigation
- les cartes recettes
- les couleurs et composants UI


## Étape HTML


Création de la structure de navigation avec :

- header
- nav
- liste de liens
- structure sémantique HTML5

## Hero Section

Création d’une section principale contenant :

- un titre principal
- un texte descriptif
- un filtre par âge
- une barre de recherche

## Cartes recettes

Création de cartes HTML contenant :

- une image
- un titre
- l’âge recommandé
- un bouton d’action

## Gestion des catégories d’âge

Les recettes sont organisées par tranche d’âge :

- 4 mois+
- 6 mois+
- 9 mois+
- 12 mois+

afin d’accompagner l’évolution alimentaire du bébé

## Mise en place du CSS global

Création du style principal du site :

- reset CSS
- couleurs globales
- navbar responsive avec Flexbox
- hero section

## Mise en forme CSS des cartes recettes

Création d’un design moderne avec :

- Flexbox
- hover animation
- ombres
- border-radius
- responsive layout
